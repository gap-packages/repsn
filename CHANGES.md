This file describes changes in the Repsn package.

## 3.1.2 (2024-01-22)

  - Simplify some code using `List` and `ListX`
  - Fix typos in the manual and update the CI setup

## 3.1.1 (2023-03-20)

  - Fix `IrreducibleAffordingRepresentation` for characters with trivial
    kernel, and for groups that are not permutation groups

## 3.1.0 (2019-02-22)

  - Fix a regression in `PerfectRepresentation`
  - Generate the manual with AutoDoc, and fix various documentation issues
  - Add a test suite, continuous integration and code coverage support
  - Add the GPL-2.0-or-later license (with the author's permission)
  - Convert the README to Markdown and update the package metadata

## 3.0.2 (2011-08-25)

  - Update the package metadata and documentation

## 3.0.1 (2008-12-10)

  - Add support for constructing projective representations, via
    `ProjectiveReps`, `GeneratorsProjective` and `GallagherRepsn`
  - Add the helper functions `FilteringCharacters`, `IrrRepsNotPrime` and
    `SocleMoreComponents`
  - Remove `RepresentationSpecialCharactersMaximal` and
    `RepresentationSpecialCharactersSubgroup`
  - Rework large parts of the representation construction code

## 2.1.0 (2007-02-25)

  - Fix the construction of linear representations of the trivial permutation
    group

## 2.0.0 (2006-01-01)

  - Add support for reducible representations, via `IsReducibleRepresentation`,
    `ConstituentsOfRepresentation`, `EquivalentBlockRepresentation` and
    `DiagonalBlockMatrix`
  - Add `StandardSubgroups` and `AllCharacterStandardSubgroups`, and use them
    when searching for a suitable subgroup

## 1.1.0 (2004-04-25)

  - Janitorial changes

## 1.0.0 (2004-04-25)

  - Initial release
